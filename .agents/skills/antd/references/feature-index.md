# Feature Index

Use this file to choose the smallest Ant Design reference needed for a task.

| Feature / Task | Read |
|---|---|
| Align GetTokens or UI language to Ant Design principles | `design-language.md` |
| Write or refactor AntD components | `component-workflows.md` |
| Query component props, docs, demos, semantic selectors, or tokens | `component-workflows.md` |
| Diagnose AntD project issues | `debugging-and-migration.md` |
| Migrate AntD versions or inspect changelogs | `debugging-and-migration.md` |
| Analyze project usage or lint deprecated/a11y/performance issues | `component-workflows.md`, then `debugging-and-migration.md` |
| File AntD or `@ant-design/cli` bugs | `reporting-and-cli.md` |
| Upgrade `@ant-design/cli`, collect environment, or use MCP mode | `reporting-and-cli.md` |
| Change TritonKit `Web/` AntD mock UI | `tritonkit-web-notes.md` |
| Check global flags and always-on CLI usage rules | `flags-and-rules.md` |

If no row fits, add a focused reference for that repeated workflow instead of expanding `SKILL.md`.
