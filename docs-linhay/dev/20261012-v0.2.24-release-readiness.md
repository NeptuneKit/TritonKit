# v0.2.24 发布准备契约

本次统一podspec、Web manifests为0.2.24，CLI及合并public skills由发布流水线按tag stamp；SwiftPM不增加版本字段。公开notes见对应SP183发版准备记录。SKILL只表达产品契约与调用前授权，历史验收与操作遗留保留space，不让“本轮未授权”成为永远禁用的产品描述。

发布仍使用独立Release工作流：arm64 CLI/Web、public skills、checksum、Homebrew先完成，x86_64作为同tag回填。当前阶段不推送main、tag或Release，不向CocoaPods trunk发布。私有diagnostic和证据不打包。

## 工具链验证边界

标准 `pod lib lint TritonKit.podspec --allow-warnings --skip-tests` 在本机 Xcode 27 失败：生成的 App/Pods 工程使用产品最低 iOS 13，当前 SDK 仅支持 iOS 15 及以上。保持 podspec 的 iOS 13 声明。另以私有 `XCODE_XCCONFIG_FILE` 设置 `IPHONEOS_DEPLOYMENT_TARGET = 15.0`，同一 lint 退出 0 且明确返回 `TritonKit passed validation.`。这证明当前工具链上的编译与集成，不证明 iOS 13 兼容；该缺口随后由 main c3887682 的云端标准 lint 补齐（CI 38201067605，Validate Podspec (TritonKit) success）；本机覆盖验证仍单独保留。两份日志保留在工作树私有 `.triton/release-prep-0.2.24/`，不进入公开包。

## 发布授权与单一发布路径

用户已追加明确推送/tag/发布授权。CI 仅负责验证，旧 CI 的六个 build/package/publish/tap job 显式停用；独立 Release 工作流负责双架构构建、技能包、checksum 和 Homebrew。门禁逐 job 检查停用条件，防止同 tag 被两条流水线上传覆盖。
