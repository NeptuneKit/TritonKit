## Homebrew install guidance in skills

- 同步 Homebrew 二进制安装与更新信息到项目级 skills。
- `tritonkit-real-project-regression`：真实项目回归优先使用 released Homebrew `triton` CLI；只有验证未发布本地源码时才使用 `swift build -c release --product triton`。
- `tritonkit-dev-feedback`：iOS 接入 checklist 增加 `brew install NeptuneKit/tap/triton`、`brew update && brew upgrade triton`、GitHub Release 资产和 fallback 说明。
- `tritonkit-ops-governance`：记录默认 tap `NeptuneKit/homebrew-tap`、`TAP_GITHUB_TOKEN` 要求，以及对外接入文档/skill 的 Homebrew 优先口径。

## CI-written CLI and skill versions

- 决策：CLI 与对外发布的 skill 包必须携带同一个 CI 解析出的版本号。
- `v*` tag 构建解析为正式版本，例如 `v1.2.3` -> `1.2.3`；非 tag 构建解析为 `0.1.0-dev+<short-sha>`。
- 新增 `TritonKitBuildInfo.cliVersion`，CI 构建前用 `docs-linhay/scripts/write-cli-version.sh` 写入 `Sources/TritonKitCLI/main.swift`，`triton version --json` 读取同一个常量。
- 新增 `docs-linhay/scripts/stamp-skill-version.sh`，CI 打包 skill 前向 `SKILL.md` front matter 写入 `metadata.version` 字段，保持 skill validator 兼容。
- 新增 `docs-linhay/scripts/verify-version-stamping.sh` 覆盖版本解析、Swift 版本常量写入和 skill front matter 更新。
