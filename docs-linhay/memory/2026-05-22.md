## Issue 21 server 不可达日志降噪

- 在独立 worktree `../TritonKit-worktrees/20260522-issue-21-server-log-noise` 处理 GitHub issue #21，避免与 #20 tap activation 并行改动串工作。
- 根因：`TritonKit.connect` 在 server 未启动时直接创建并 resume `URLSessionWebSocketTask`，本机端口拒绝连接会触发 `NSURLErrorDomain -1004`，同时可能伴随 Network.framework `nw_*` 噪声。
- 修复：创建 WebSocket 前增加短超时 TCP readiness probe；探测失败时保持 `disconnected` 并按配置继续 reconnect，不创建 WebSocket task，不向 delegate / `onError` 暴露 connection refused。已建立连接后的 send/receive 错误仍保留原有错误通知路径。
- 验证已通过：`swift test --filter TKPlatformFallbackTests`、`swift test`。
