## Cruise mode artifact output safety

- 继续推进自动巡航第二个小切片：stdout-backed artifact 输出安全。
- 先补红灯测试：已有 output 文件不能被 `runHostCommandWritingStdoutArtifact` 覆盖，output 为符号链接时不能跟随写入。
- 实现：artifact 输出默认 create-new，先拒绝已有文件和符号链接，再用 `O_EXCL | O_NOFOLLOW` 打开目标文件，降低 agent 自动执行时覆盖非预期文件或跟随 symlink 的风险。
- 新增稳定错误码：`artifact_output_rejected`，并同步 CLI schema、README、AI CLI readable control、Xcode workflow skill 和巡航审计报告。
- 复核时发现流式写 artifact 后，非零退出会留下 partial/empty artifact；补红灯测试并改为非零退出 / 写入错误时删除 partial artifact，避免 agent 读取坏产物。
- CLI 冒烟确认 `coverage report` 输出已有文件时只返回单一 `artifact_output_rejected` envelope，不再被外层 catch 二次包装为 `host_action_failed`。
