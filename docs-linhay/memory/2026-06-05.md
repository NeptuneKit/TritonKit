## 会话整理：Debug runtime / SPM / 用户接入口径沉淀

- 沉淀模式：涉及 Package Manager Debug-only runtime 时，应拆分三层边界：package 内部 `TRITONKIT_RUNTIME_ENABLED` Debug compile flag 控制 runtime、业务 App 源码级 `#if DEBUG` bootstrap 控制引用点、显式 `TRITON_ENABLED` / `--triton-enabled` 控制普通 Debug 包是否启动。
- 沉淀模式：SwiftPM 支持 configuration-scoped build settings / compile conditions，但不支持 CocoaPods-style configuration-scoped product dependency；若 Release 必须完全不链接 TritonKit，仍需独立 Debug-only target / scheme。
- 沉淀模式：用户接入面只显式选择 / 添加 `TritonKit`；`TritonKitShared` 保留为内部 shared-contract module，并由 SwiftPM target dependency / `TritonKit.podspec` 传递解析。
- 写回：已同步 `AGENTS.md` 与 `.agents/tritonkit-skills/internal/tritonkit-ops-governance/SKILL.md`，避免后续 agent 复用旧口径。
