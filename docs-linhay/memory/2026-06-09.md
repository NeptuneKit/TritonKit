# 2026-06-09

## Issue 30 Android contract compatibility

- 为 GitHub issue #30 做字面契约收口：`triton app inspect --platform android --bundle <package> --json` 作为 Android `dumpsys package` metadata inspection 兼容入口，输出 `HostAppInfoOutput` / `host.android-app-inspect`。
- `triton ax --platform android --device <selector> --json` 作为 Android UIAutomator layout 兼容入口，复用 `observeAndroid` / `hostCaptureAndroidLayout`，输出 `HostAndroidArtifactOutput` / `host.android-ax`。
- schema 显式暴露 Android host platform-specific contracts：`host.android-device`、`host.android-app-inspect`、`host.android-app-install`、`host.android-app-launch`、`host.android-screenshot`、`host.android-ax`、`host.android-tap`、`host.android-wait`、`host.android-key-action`。
- `CLI/Package.swift` 使用显式 package identity `.package(name: "tritonkit", path: "..")`，避免 feature worktree 目录名不是 `TritonKit` 时 SwiftPM 解析本地依赖失败。
