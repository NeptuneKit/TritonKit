## Issue 45: Host Foreground App Identity

- 在 `docs-linhay/spaces/20260612-issue-45-foreground-app-identity/` 落地需求边界：本轮只做本机 CLI + emulator 的 host adapter / schema 契约，不新增 Web/Wails 控制入口。
- `triton device list --platform harmony --json` 的 `HostDeviceTarget` 可选暴露 `appName`、`bundleIdentifier`、`identityState`、`current`；`current=true` 仅在 HDC 前台 mission 能稳定解析时出现。
- Harmony HDC 前台身份不可稳定取得时必须返回 `identityState=unknown`，host 命令不可用时返回 `identityState=unsupported`；禁止把 HDC target id、emulator 名或 alias 猜成 App identity。
- schema/capabilities/public skills 已同步 `harmony-foreground-app-identity` 能力，后续 agent 应从 `host.device-list` output contract 读取该可选字段，而不是解析人读输出。
