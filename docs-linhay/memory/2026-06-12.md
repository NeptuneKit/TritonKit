## Proxy export capture event summary

- `device proxy export --session` / `sim proxy export --session` 的 `NetworkProxySession` 导出摘要新增 `eventCount` 与 `failureCount`，配合既有 `requestCount`、`redaction`、`truncation` 让 agent 不读取 artifact 也能判断 capture proxy 是否观察到事件、是否有 `proxy.serve.connection-failed` 等失败。
