# 2026-06-12

## Issue 42 nested pager swipe targeting

- 为 `triton swipe` 的 embedded UIKit runtime 增加轴向滚动祖先选择：横向手势优先选择可横向滚动的 `UIScrollView` 祖先，纵向手势优先选择可纵向滚动祖先；无轴向匹配时回退最近 scroll view。
- `TKInputResult.strategy` 会返回 `axis-matched-scroll-ancestor` 或 `nearest-scroll-ancestor`，方便 agent 解释嵌套滚动命中路径。
- 新增 `docs-linhay/spaces/20260612-issue-42-nested-pager-swipe/README.md` 记录 BDD、范围和验收；UIKit 嵌套 pager 用例已补入测试资产，当前 macOS SwiftPM 环境不发现 UIKit suite，后续 iOS/Catalyst 测试入口可直接启用。
