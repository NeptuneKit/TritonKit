## GitHub #39 / #44 capture/evidence target 透传核验

- #39 与 #44 是同根 bug：多 iOS Simulator runtime target 下，`triton capture --target <id>` / `triton evidence --target <id>` 顶层能解析显式 target，但 nested artifact collector 继续用默认 `triton:local`，导致 hierarchy、AX、screenshot、geometry、archive 被 server 以 `ambiguous_target` 跳过。
- 本 worktree 既有本地 commit `6bc275c Fix evidence target propagation` 属于该 issue：它在 `captureEvidenceBundle` 的 `list` include 解析出 `TKTargetSummary` 后，把 runtime client 重建为 target-scoped client，并新增 fake 多 target server 测试覆盖 `hierarchy`、`accessibility`、`screenshot`、`geometry` 和 archive 内部子请求。
- 当前未提交的 `CLI/Package.swift` 修改不属于 capture/evidence 运行时修复；它是 worktree 目录名不叫 `TritonKit` 时让 `swift test --package-path CLI` 能直接解析根包 identity `tritonkit` 的测试支撑改动。
