## 编译 triton 并启动 Web 脚本

- 新增 `docs-linhay/scripts/start-web-with-triton.sh`，用于本地先构建 `triton` CLI，再启动 `Web` Vite dev server。
- 默认使用 Debug 构建和独立 scratch path `.build/web-dev-cli`，避免覆盖 release 验证产物；需要发布形态时可传 `--release`。
- 脚本启动 Web 时显式注入 `TRITONKIT_TRITON_BIN=<built-triton>`，确保 dev bridge 使用本轮构建产物。
