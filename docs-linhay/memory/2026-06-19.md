# 2026-06-19

## issue #66：Xcode DerivedData 增量缓存语义

- 需求：让 `triton xcode build` 的默认 `.triton/DerivedData` 增量缓存行为对 agent 可见，避免误以为每次都是全量构建或默认清理缓存。
- 实现：新增 `TKXcodeDerivedDataCacheInfo`，在 Xcode invocation、action summary、status / use 输出和 schema 中暴露 `path`、`exists`、`cacheState`、`incrementalExpected`、`cleanupPolicy`、`guidance`。
- 决策：不新增自动清理；`cleanupPolicy=preserve-by-default` 明确 Triton 默认不删除 DerivedData，若要重置缓存应由后续显式命令承担。
- 验证：见 `docs-linhay/spaces/20260619-issue-66-xcode-incremental-cache-ux/README.md`。
