## Issue #69 iOS Real Device App Selector

- 在独立 worktree ../TritonKit-worktrees/20260619-issue-69-ios-real-device-app-selector/ 处理 GitHub Issue #69，分支 feat/20260619-issue-69-ios-real-device-app-selector，避免污染主仓已有 WIP。
- 问题根因：iOS host-side app 命令在显式 --device ios-real:<hash> 但未带 --scope real 时仍只发现 simulator；同时 devicectl parser 未把 UDID / unique device id / serial 作为本地 selector alias。
- 修复：显式 iOS selector 默认 discovery scope 扩展为 .all，booted 保持 simulator；TKDevicectlDeviceTarget.alternateIdentifiers 与 HostDeviceTarget.rawTargetAliases 支持 CoreDevice identifier / UDID alias 匹配，敏感 alias 不进入 Encodable JSON。
- 验证通过：
  - swift test --package-path CLI --scratch-path .build/cli-issue69-green --filter 'DeviceCrossPlatformTests|TKHostAdapterModelsTests'：DeviceCrossPlatformTests 80 tests passed。
  - swift test --scratch-path .build/issue69-shared --filter TKHostAdapterModelsTests：36 tests passed。
- 剩余风险：未连接真实 iPhone 跑 live smoke；triton app list 对 iOS real device 仍返回 host action / artifact 摘要，不在本轮扩展解析完整 app list。
