## issue #68：Harmony HDC 语义失败不能返回 ok:true

- 需求：真实 Harmony target 的 screenshot 可用，但 app launch/open-url 遇到 HDC stdout `[Fail]Not match target founded` 时仍返回成功，导致 agent 误判动作已提交。
- 实现：`runHostCommand` 与 `runHostCommandWritingStdoutArtifact` 对 HDC stdout/stderr 中的 `[Fail]` 做语义失败识别，即便 exit code 为 0 也走 `HostCommandRunError.nonZeroExit`。
- 验证：补充 app lifecycle planner 对 Harmony real-device raw target 的 launch/open-url 断言；补充 fake hdc stdout `[Fail]` 测试。
- 边界：未调用真实 HDC；不 push、不关闭 issue。
