## Simulator camera CLI and frame server landed

- 新增 `triton camera on/off/status/build-hook/serve`，workspace 配置落在
  `.triton/sim-camera.json`，按 bundle allowlist 启用，不做全局注入。
- CLI target 打包 `Resources/sim-camera/TritonSimCameraHook.{h,m}`，
  `camera build-hook` 使用本机 iPhoneSimulator SDK 编译并 ad-hoc codesign
  `.triton/sim-camera/libTritonSimCameraHook.dylib`；`camera on` 未传
  `--hook` 时自动构建默认 hook。
- `camera serve` 在 Unix socket 上输出协议 v2 BGRA frame stream，默认
  socket 为 `/tmp/tritonkit-sim-camera.sock`，支持 `--width/--height/--fps`
  和 `--max-frames/--once` 方便自动化回归。
- 内置 hook 已升级为 AVFoundation 接入：注入后暴露 Triton fake back/front
  camera，拦截 `AVCaptureDevice` discovery/default/input、session
  input/output/running、`AVCaptureVideoDataOutput` delegate 和
  `AVCaptureVideoPreviewLayer` preview overlay，把 `camera serve` 的同一帧源
  分发给 sample buffer 与预览层。
- `triton app launch --bundle-id <id>` 在 iOS Simulator 且 bundle 命中配置时
  自动注入 `DYLD_INSERT_LIBRARIES` 与 `TRITON_SIM_CAMERA_SOCKET`；真机、
  Android、Harmony 不受影响。
- 验证状态：`CameraCommandTests` 通过；`swift build --package-path CLI
  --scratch-path .build/cli --product triton` 通过；`schema --command camera`
  通过；CLI smoke 通过 `camera build-hook`、默认 `camera on/status`、
  `camera serve` socket 读帧；hook dylib 使用 iPhoneSimulator SDK 可编译并
  ad-hoc codesign；`git diff --check` 与
  `docs-linhay/scripts/check-docs.sh` 通过。
