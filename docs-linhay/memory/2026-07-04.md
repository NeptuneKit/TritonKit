## Web mock hierarchy 有效可见性修正

- 用户指出当前选中的 `UITableView#767` 明显没有显示在屏幕上。排查发现该节点自身 `visible: true`，但父节点 `AMMemoryLeakView#765` 为 `visible: false`、`view.isHidden: true`、`alpha: 0`；旧逻辑只过滤节点自身 `visible === false`，导致隐藏父节点下的子节点仍出现在审查树和画面 overlay。
- 本轮新增 `Web/src/hierarchyVisibility.ts`，按父链计算有效可见节点；`InspectorCard` 和 `StreamCard` 共用该过滤，避免同类隐藏子节点继续冒出。
- 浏览器验证：刷新 `http://127.0.0.1:34127/` 后，“界面与 AX 审查”仍显示真实树根 `DUI.DUIKeyWindow`，但不再显示隐藏父节点 `AMMemoryLeakView`，也不再生成 `UITableView (83x348)` 的 overlay title。
- 验证命令：`node --test dev/hierarchyVisibility.test.mjs dev/iosRuntimeMirrorBridge.test.mjs`、`npm run build`、`antd usage Web/src --format json`、`antd lint Web/src --format json`、`docs-linhay/scripts/check-docs.sh`、`git diff --check`。
