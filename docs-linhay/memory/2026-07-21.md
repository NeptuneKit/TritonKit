## GitHub Issue #156：UIButton Primary-Action Menu

- iOS 17.4+ embedded runtime 已通过 public `UIButton.performPrimaryAction()` 打开只配置 `menu` / `showsMenuAsPrimaryAction` 的按钮，稳定 strategy 为 `button-primary-menu-action`。
- 菜单打开必须再以可见 action title 验证；TestFixture 中 `Fixture Menu Action` 由 `verify text-exists` 证明存在。
- public UIKit 没有安全接口直接执行已呈现的 `UIAction`，因此菜单项标题点击返回 `unsupported_capability` / `button-primary-menu-item-unsupported`，需要 item selection 时使用 host HID 或 App 自有 semantic DEBUG action。
- 修复 CLI input failure 双输出：已经打印的失败 `TKInputResult` 直接以 `ExitCode.failure` 结束，不再生成第二个泛化 `request_failed`。
