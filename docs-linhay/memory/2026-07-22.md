## GitHub Issue #159：UIKit modal tap boundary

- UIKit embedded runtime 的 coordinate fallback 不能只检查命中 view 的 cell ancestor；当 responder chain 属于已呈现 `UIAlertController` 时，必须先终止后续 text/control/cell/gesture resolution，避免相同坐标激活 modal 背后的内容。
- alert action 只使用公开 `accessibilityActivate()`：成功与不支持分别通过稳定 strategy `alert-action-accessibility-activate`、`alert-action-unsupported` 暴露，agent 仍需验证 dismiss 或业务后置状态。
- iOS Simulator fixture 应把 selectable collection 放在 alert 后方，同时覆盖已映射、不可激活和无法映射的 alert subtree view；三类断言都必须包含背景 selection 未变化。

## GitHub Issue #160：Xcode one-off build settings

- `triton xcode settings/build/test/run` 的临时 build setting 使用可重复 `--build-setting KEY=VALUE` 表达；key 在 host command 前按 `[A-Za-z_][A-Za-z0-9_]*` 验证，value（包括空值、空格和 `$(inherited)`）保持原样。
- 共享 Xcode builder 必须逐项追加 setting argv，不能用 shell 字符串拼接；机器可读 schema 同时暴露 `KEY=VALUE[]`、适用 subcommand 与 `validation_failed`，parent failure codes 也必须覆盖子命令。
- fake `xcodebuild` smoke 应同时校验 argv 边界、可审计 `sourceCommand`，以及非法 setting 不启动 host command。
