## SP-156 · GitHub #176 Xcode compact progress（本地完成）

- 根因是 Xcode streaming runner 会把每个 stdout/stderr chunk 直接复制为 JSONL progress；大型 workspace 的完整 log 已有 artifact，却仍把普通编译输出重复送入 agent 通道。
- `triton xcode build` 新增稳定 `--progress compact|full`，默认 compact：保留 invocation、heartbeat、每类最多 20 条 redacted/length-bounded warning/error、artifact path/bytes 与 final summary，完整原始输出继续写 log。显式 full 恢复旧 chunk stream；settings/test/run 保持既有 full 默认。
- JSONL progress/final 保持 stdout 顺序，JSON progress 写 stderr 且 stdout 只有最终 envelope；实现只在 CLI Xcode 层并将 streaming runtime 从过长的 `CLIXcodeRuntime.swift` 机械拆到独立文件，未修改 shared model、runtime/device/Web 或真实 Xcode 状态。
