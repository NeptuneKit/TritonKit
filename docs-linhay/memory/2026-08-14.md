## 会话整理与可复用模式沉淀

- 本轮实践确认两条可复用 repo-wide 规则并沉淀：
  1. **多 worktree 并行禁止 `git stash`**——stash 是仓库级全局、跨 worktree 共享，一次 push/pop 会串扰其它 worktree 的暂存内容（本会话 #204/#205 subagent 各遇到一次跨 worktree stash 碰撞，需改临时分支/独立文件保存中间态）。已写入 `AGENTS.md` §2.7 与 `tritonkit-ops-governance` skill。
  2. **CocoaPods lint 比本机 SwiftPM 更严格**——ObjC-interop 固定布局下会强制检查 memberwise init 实参声明顺序，本地 `swift test` 通过、`pod lib lint` 仍可能报 `argument 'X' must precede argument 'Y'`（本会话 v0.2.19 发版前 CI 抓出 SP-167 WebView DTO 此问题，integration fix `d924253c` 修复）。发布门禁必须含 `pod lib lint`。已写入 `tritonkit-ops-governance` skill。
- 本会话代码与文档均已按 issue/branch 提交并推送至 `origin/main`，release v0.2.19 已发布；此整理仅含 `AGENTS.md` 与 skill 的模式沉淀 + memory 记录，属 docs/skill-only 改动，走 `verify.sh --ci-docs` 门禁通过。
