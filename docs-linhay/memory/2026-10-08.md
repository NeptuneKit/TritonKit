## SP-182：新可信执行系统设计

用户进一步明确：设计的是新的可信执行系统，已有零散能力要聚合、封装、消融。[设计space](../spaces/SP-182-trusted-execution-system/README.md)、[架构ADR](../dev/20261008-trusted-execution-system-architecture.md)、[消融迁移与BDD](../spaces/SP-182-trusted-execution-system/plans/20261008-convergence-migration.md)已归档，未实施产品改造。

### 新设计基线

- 一个权威ExecutionKernel，不给旧命令再套万能session，也不增加与workspace/replay平行的第四个runner。
- 主控+只读subagent核查：已有workspace有界动作循环和executed_unverified/verified分离；replay仍独立顺序fail-fast，record只是template，InputResult已有verification boundary。吸收资产，不假装从零。
- SessionContext负责revision化绑定；Run为执行聚合根；Step/Attempt分离意图与发送事实。execution/verification/recovery/evidence四维，trusted gate显式；模型done/ACK/dry-run/capture.ok均不等于业务成功。
- 统一bind/observe/resolve/guard/dispatch/verify/reconcile/evidence commit；CLI/HTTP/旧replay/workspace降为适配与投影，平台adapter只返回facts。
- 未知交付不盲重试/跨backend双发；持久journal不消除崩溃窗口；lease不锁外部GUI/人手；不承诺exactly-once/通用业务rollback/hash真实性。
- 首片compiler/reducer失败测试，再一个iOS runtime动作三入口共内核；第二平台与环境later。shadow只比较纯决策，不双发。trusted模式不可静默回退旧runner并保留trusted标签。
- 旧wire/plan/evidence继续兼容，明确primitive/unmanaged保证；不可把脱敏preview argv当真实执行IR。消融以调用方/重复裁决删除和测试证明，不以减少文件行数验收。

本轮保留SP-181未提交改动与已有ahead1提交；docs-only，无Git/设备/设置/服务副作用。跨进程写协调和实际故障/平台行为未测试；公共skill待实现schema后再更新，不把proposal当现有命令。文档门禁 `verify.sh --ci-docs`、`check-docs.sh`、`git diff --check` 全部exit0，182 spaces一致；4份架构相关文档35个本地链接/行锚核查通过，最终元数据写回后复验。

### SP-182关键修正：双操作路径是一等能力

用户明确两点：agent依旧能手动组合单点命令开展工作流，也能使用封装高级命令。此前“一切动作都是Run/唯一高级入口”的过强表述已纠正：消融重复底层执行与事实裁决，不消融agent编排自由。

- 单点observe/act/verify/evidence为独立Operation，直接调用共享ExecutionCore，不强制run ID/session/model或完整postcondition；返回自己请求的事实，不冒称整体业务成功。
- 高级命令使用WorkflowEngine管理Run/预算/资源/验收/证据，复用同Core；不另开backend dispatch，不shell串联假聚合。
- 两种方式可以混用，写协调/owner一致；进行中的高级Run不被未授权单点接管。有效手动verify可证明同样声明条件，不能因无Run就称为不可信。
- ADR/语义契约/迁移BDD/space已修正，[PNG v2](../spaces/SP-182-trusted-execution-system/screenshots/20261008-architecture-overview-proposal-v2.png) 与 [SVG v2](../spaces/SP-182-trusted-execution-system/20261008-trusted-execution-architecture-v2.svg) 清楚画出A直接Core、B可选WorkflowEngine；v1保留为历史草图。主控已打开v2检查连线/中文。
