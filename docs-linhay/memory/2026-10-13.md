# 2026-10-13

## SP-191 默认使用 Xcode 全局 DerivedData

- 用户反馈仓库内 `.triton/` 因构建缓存过大；默认 Xcode workflow 现不再传 `-derivedDataPath`，交给 Xcode 使用 `~/Library/Developer/Xcode/DerivedData` 下的用户级默认布局。
- `--derived-data-path` 改为显式 opt-in，只用于隔离、复现或恢复；CLI help/schema/skill 明确该参数可能造成高磁盘占用，非必要不要开启。
- `TKXcodeWorkspaceDefaults.derivedDataPath` 允许为空；旧保存的 `.triton/DerivedData` 默认值迁移为 Xcode 默认，显式传参仍保留。
- `derived-data inspect|cleanup` 默认检查用户级 Xcode root；`.triton/DerivedData` 仍可显式检查，confirmed cleanup 继续 fail closed。
- 显式 legacy `.triton/DerivedData` 的 `derivedDataCache.guidance` 会提示 agent：若磁盘占用过大，先询问用户是否清理，再执行任何删除；当前 cleanup 仍不删除文件。
- focused CLI 测试覆盖默认命令不含 `-derivedDataPath`、显式覆盖、旧配置迁移、默认 inspect root 和 schema 文案；CLI 全量 1194 项、根包 264 项、CLI build、docs check 与 `verify.sh --ci-docs` 均通过。

## 发布前门禁

- 版本统一到 `0.2.26`；`verify-release-package-versions.sh`、`verify-release-automation.sh`、`verify-skill-package.sh`、`check-docs.sh`、`TRITON_VERIFY_XCODE=0 verify.sh --local`、Web production build 均通过。
- 本机标准 CocoaPods lint 受 Xcode 27.1 不再支持 iOS 13 模拟器目标影响；按既有流程使用临时 `XCODE_XCCONFIG_FILE` 将 lint 构建目标设为 iOS 15，`TritonKit passed validation.`，podspec 对外仍保持 iOS 13。
