静态核对结论：Pinky 是 Go/MyGo 本地优先跨平台手机操作网关，MCP stdio/Streamable HTTP 接入；gateway 统一承载 driver、session/lease、policy/approval、screen/diff、history；Android 为 adb+scrcpy+Kotlin accessibility companion；iOS 为 go-ios/CoreDevice/WDA。审批只由客户端决定，绑定 session/device/lease/tool/args，动作结果区分 `uncertain`、`stale`、`blocked_by_policy`、`approval_pending`、`device_needs_setup` 等。与 TritonKit 的 target lease、typed action result、evidence、Android/iOS provider 和 MCP/HTTP 边界有较高参考价值，但没有自动形成产品采用任务。

风险和未知已保留：项目自述 pre-alpha，ACCEPTANCE 仍有大量未勾选项；本轮未执行 Pinky、Go/Kotlin 构建、第三方依赖、MCP 服务、真实设备、模拟器或网络安全测试；iOS 跨平台、OEM 锁屏、Android 11/12 后台、FFmpeg/adb 打包、Apple DDI 与依赖许可证仍需独立核对。README 明确同一用户的 shell/adb 能绕过 gateway，不能把网关策略描述成宿主安全边界。
