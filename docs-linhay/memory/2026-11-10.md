# 2026-11-10

## 发布边界：iOS 16+ / SwiftPM-only

- 用户明确将 iOS 支持下限收口为 iOS 16，`Package.swift` 已从 iOS 13 改为 iOS 16。
- CocoaPods 从产品支持列表移除：删除 `TritonKit.podspec`、`TRITONKIT_COCOAPODS_SINGLE_POD` 条件编译分支、Podspec CI/release 校验和公开 Podfile 接入说明。
- iOS embedded SDK 当前唯一支持分发路径为 SwiftPM Git tag；Debug runtime 仍由 `TRITONKIT_RUNTIME_ENABLED` 控制，App 侧继续要求文件级 `#if DEBUG`。
- CocoaPods 历史设计文档保留为已退休记录，不再作为当前验收或发布门禁。
- 发布候选版本为 `0.2.43`，Web package manifests 已同步；SwiftPM 无版本字段，按 Git tag 解析。
