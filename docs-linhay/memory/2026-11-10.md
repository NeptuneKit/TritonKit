## 客诉排查：v0.2.43 Homebrew 与 iOS 触摸

客诉拆成两个独立阻塞：`NeptuneKit/TritonKit#282` 的 Homebrew formula 无 `bottle`，Homebrew 会进入 source-install lifecycle 并受 Xcode/CLT 版本门槛影响；原始记录为 0.2.40→0.2.43，当前复核机在自动刷新 Homebrew 元数据后为 0.2.42→0.2.43。`~/.local/bin/triton` 解析后仍指向 Homebrew Cellar，不能作为手工 0.2.43 已安装证据。已将现状和修复建议补到 [issue #282](https://github.com/NeptuneKit/TritonKit/issues/282#issuecomment-6765135080)，未发布私有路径、目标标识或原始日志。

独立的 iOS 触摸缺陷是发布遗漏：`v0.2.43` 不包含 `5e1c0b74` / `cbaf0641` 之后的 DTUHID 修复；Xcode 27 / iOS 27 Device Hub 场景仍会返回 `ios_host_hid_device_hub_attached`，即使框架兼容、截图成功也不代表触摸分发。下一 patch 必须包含该修复，并用 exact-target `doctor → act tap --hid-only → observe/verify/evidence` 重新验收；Homebrew bottle/分发问题另行处理。
