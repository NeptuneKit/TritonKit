# 20260706 Phase 0 Scope

## 目标

把 Revyl-like 产品方向收敛成 TritonKit 可执行的一期切片：本地单机 agent mobile runtime platform。target 可以是真机、模拟器或仿真器，产品入口按 `platform + scope + capabilities` 抹平差异，并把完整 Atlas map 与 VLM 自主探索 loop 纳入必做范围。

## 切片

1. 固化已接入基础能力清单：target/capability、app lifecycle、observe、action、evidence、replay、VLM grounding、semantic provider、Web stream/inspector。
2. 盘点现有 CLI/HTTP schema：target、scope、capabilities、app lifecycle、action、observe、evidence、plan、vlm。
3. 补齐缺口清单：只列缺口，不直接大改。
4. 定义 runtime session DTO：复用已有 target/session 字段，避免新增抽象。
5. 选一个本机 target scope 做 smoke baseline，优先当前最稳的 iOS Simulator 或 Android Emulator，但 DTO 不绑定该 scope。
6. 定义本机 Atlas map DTO：screen、state、transition、coverage、evidence backlink。
7. 定义 VLM explore loop 边界：observe -> decide -> act -> verify -> record，所有动作经由 Triton CLI/HTTP。
8. 决定 Web 新插槽只读 DTO 形态。

## 验证门禁

- 文档自检：`docs-linhay/scripts/check-docs.sh`
- 空实现阶段不跑 Swift/Web 自动化测试；进入代码切片后再按 touched surface 跑 focused tests。
