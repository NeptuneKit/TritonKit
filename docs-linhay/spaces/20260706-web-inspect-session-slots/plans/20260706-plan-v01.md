# 20260706 Plan V01 - Web Inspect Session Slots

## 目标

把 Web mock 的插槽联动从组件私有状态改为统一 Inspect Session：

- Slot Shell 只管布局。
- Slot Binding 管跟随 / 固定规则。
- InspectTarget 管设备身份和 source。
- InspectSession 管 hierarchy、overlay、节点选中、刷新状态。
- derive / hit-test 管 View tree、AX tree、overlay nodes 和点击命中。

## 阶段

### P0 文档与红灯测试

- 建立本 space。
- 新增模型测试的失败用例：
  - iOS simulator refresh 必须带 `source=host`。
  - iOS real-device refresh 必须带 `source=runtime`。
  - session selection 必须按 target 隔离。
  - stale request 不能覆盖新 session。
  - AX derive 保留 cell grouping。
  - hit-test 在 selected ancestor 内优先下钻。

### P1 Target 与 Session Store

- 新增 `Web/src/inspect/target.ts`。
- 新增 `Web/src/inspect/sessionStore.tsx`。
- 新增 `Web/src/inspect/hierarchyQuery.ts`。
- AppContext 只暴露 session API，不再暴露裸 `hierarchyScenes` 作为主要事实源。

### P2 Derive 与 Hit Test

- 新增 `Web/src/inspect/hierarchyDerive.ts`。
- 新增 `Web/src/inspect/hitTest.ts`。
- 把现有 View simplify、AX filter、overlay node filter、descendant hit-test 迁入纯模型。
- 保留 `UITableViewCell` / `UICollectionViewCell` / `AXCell` grouping。

### P3 Stream Slot 接入

- Stream slot target 选择写 workbench focus。
- overlay mode 写 session。
- gesture success 后刷新 session。
- overlay nodes 和点击命中全部来自 derive / hit-test。

### P4 Inspector Slot 接入

- Inspector slot 通过 binding resolve target。
- tree / details 全部来自 session。
- tab 切换同步 overlay mode。
- manual refresh 走 `refreshInspectSession`。
- 删除 `activeStreams` 距离推断与本地 hierarchy query。

### P5 验证

- `cd Web && npm test`
- `cd Web && npm run build`
- Browser smoke：iOS simulator cell 点击、View / AX tab 与 overlay 同步、gesture 后 Inspector 更新时间更新。
- `docs-linhay/scripts/check-docs.sh`
- `git diff --check`

## 风险

- 当前 `AppContext` 仍被多个组件直接消费，迁移时要避免一次性破坏所有插槽。
- `selectedNodeId` 从全局迁移到 per-session 会影响已有 overlay / Inspector 联动测试。
- 当前 screenshots 目录被 `.gitignore` 的 `screenshots/` 规则忽略，browser smoke 截图只能作为本地验收产物，除非另行调整 ignore 规则。

## 不做

- 不引入新状态库。
- 不新增平台后端采集。
- 不把 Web 变成正式业务控制面。
- 不保留组件各自 fetch hierarchy 的临时兼容路径。
