# TritonKit v0.2.24

## Device Hub 与真机

- 接入 Xcode 27 元数据布局并保留旧布局兼容，严格区分 Simulator 与物理设备身份，改善就绪和硬件来源报告。
- App/App Group 容器由 SDK bundle/group membership 与路径绑定；文件域、DeviceFS浅层目录和整机诊断分别定义，不读取业务文件正文。
- pair/unpair/diagnose 提供明确授权、持久审计和原生file JSON验证的执行路径；配对校验独立后置状态，诊断支持私有ZIP、安全发布与预算拒绝。修复原生timeout整数秒参数。
- Temporary查询可能创建域，需显式策略；不会将其标为纯只读。

## 专门平台与兼容

- watchOS配对信息与Apple物理硬件元数据目录；非iOS物理设备证据仍以fixture为主。
- watchOS Crown/Action与tvOS遥控提供显式XCTest runner门禁：精确测试/设备绑定、版本化请求、原生xcresult附件、持久审计，未知输入不自动重试。
- 独立watchOS/tvOS测试工程编译通过；缺匹配runtime，真实输入未验收。watch侧键、visionOS空间输入及macOS Device Hub控制仍未支持。macOS Xcode工作流保持独立。
- 保留旧Xcode命令与参数；更新新旧SDK fixture及CLI schema。修复所选Xcode framework加载路径与Simulator平台分类。

## Skills与验证

- 整理公开skills的Device Hub引用入口与授权/证据分层，公共包不包含内部治理流程或私有诊断。
- 实测覆盖iPhone元数据、App/Group身份绑定、pair/unpair、测试App安装启动以及诊断归档；单机通过不等于全平台完整接入。
- CLI/SDK/public skills/Web/podspec按v0.2.24契约对齐；SwiftPM由Git tag选择，CLI与skill版本在正式打包时stamp。

发布包含 macOS arm64/x86_64 CLI（内置 Web）、完整四技能包及 SHA-256 清单。主分支 CI、标准 CocoaPods lint 与 Release 工作流通过；CocoaPods 未推送至 trunk。
