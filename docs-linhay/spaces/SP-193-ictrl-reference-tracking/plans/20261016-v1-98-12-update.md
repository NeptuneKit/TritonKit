## 新增机制及安全变化

| 主题 | 已读到的上游事实 | TritonKit 可借鉴价值与边界 |
| --- | --- | --- |
| LAN/AWDL发现 | 显式开启后发布Bonjour；LAN与AWDL分开listener/通道，AWDL依赖Mac客户端。Python可跨OS发现LAN，C客户端新增macOS附近发现。发布状态区分enabled、advertising及未就绪原因（nearby状态针对AWDL，不证明LAN公告成功）；监听失败退避重建，awdl0接口index变化后重新注册 | 借鉴“开关已开≠服务就绪”的事实表达及有界重试；不默认新增LAN、AWDL广播或远端产品面 |
| 配对限流 | 删除按客户端名称缓存10分钟信任的捷径；正常模式每次配对走审批（开发一次性入口例外见下文），60秒超时，拒绝后15秒冷却，429带重试提示；本机/USB和远端分别占位 | 借鉴审批与诊断互不饿死、请求ID绑定提示生命周期；本轮未接入新配对协议 |
| 设备身份 | `/whoami`、响应header及Bonjour提供per-installation随机ID；客户端密钥按设备而非host:port存储，旧key仅在成功验证后迁移，保留旧记录 | 同一地址可转发到不同手机；地址/可发现ID不能作为认证身份。只有已认证响应才支持信任或密钥迁移 |
| 来源与配置 | server在认证后覆盖注入peer来源；开启nearby只允许本机/USB来源；config在改动前校验当前支持的参数约束并串行化处理，避免先改部分设置再失败 | 值得单独评估配置完整预检与来源可信度；不把客户端自报source当权限事实，也不把此实现等同通用事务/回滚保证 |
| 诊断日志 | logs/recent_logs和无写参数config轮询仍计时统计；正常轮询不刷请求与耗时日志，失败仍记录 | 可评估高频只读诊断的日志噪声，保持失败与占用请求可追踪；本轮未评估TritonKit现有噪声量 |
| Companion App | 独立App经审批与加密RPC管理授权客户端、撤销与读取Runner日志，不绕过Runner授权；共享导入pairing file复用原验证/存储路径，并反馈失败 | 借鉴管理端不绕过认证、导入复用验证；不将此App管理写操作移入TritonKit只读Web |
| 兼容性 | peer分类避免加载旧系统缺失的新Network属性；打包补Runner Bonjour声明，诊断Local Network拒绝；DDI仅新增分享导入入口，签名脚本和DDI挂载实现未在本差异变更 | 无TritonKit跨OS/签名/DDI兼容性结论；不自动签名、挂载、导入配对材料或安装上游产物 |

## 必须保留的安全限制与反证

1. [be215869安全修复](https://github.com/OpenMinis/iCTRL/commit/be2158693f81695b762d8306b54e4494eeb1cd67)：配对提示补实际公钥指纹；`/whoami`撤去跨源读取许可，设备ID header不再列入浏览器expose列表。这是浏览器读取限制，不是给公开设备ID增加认证。
2. [0ca355ee客户端加固](https://github.com/OpenMinis/iCTRL/commit/0ca355eefda4df48c77e65838525164d9652cc96)：未认证设备header变化不能触发自动新配对；mDNS压缩指针最多32跳、记录边界检查；C旧key迁移先验证响应MAC。发现名称/ID仍可被网络参与者仿冒，应人工核对配对指纹。
3. 上游Release明确：无密钥端点也能经AWDL访问；屏幕流在所有通道均未加密；LAN广播的系统主机名可能含所有者姓名；屏幕关闭可能影响AWDL发现。以上没有因RPC envelope加密而消除。
4. Python无第三方密码学依赖是上游的实现选择，不代表本轮密码学审计通过。`nc -A`回退会改变Local Network进程权限边界，不作为TritonKit应自动采用的方式。
5. config重启listener当前采用0.3秒延迟安排，目的是避开响应连接先被关闭；没有绑定实际响应发送完成回调，也没有证明重启成功或支持失败回滚。不能把返回的restarted字段当已完成重启的验收。
6. 源码仍保留`ICTRL_ALLOW_AUTH_ONCE`开发一次性免审批入口，其条件为`!nearby`，不等同仅本机。因此Release所称每次配对审批不能概括为所有配置下的绝对保证；见[AuthManager固定源码](https://github.com/OpenMinis/iCTRL/blob/d88bbf0b3a5addead31b4298d605d7ac7a87d6e7/iCTRLKit/AuthManager.swift#L167)。
7. [d7d39bdc](https://github.com/OpenMinis/iCTRL/commit/d7d39bdcbeb802f2dc5d8f858dbb421281d18c07)将地址缓存降至30秒、失败后重查，并称陈旧地址约4秒恢复；这是上游自述，未经TritonKit本地测量。本轮未运行任何第三方代码或设备验证。
