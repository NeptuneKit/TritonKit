## BDD 与最小验收

1. Given 后续任务，When 读取根规则或命中内部 skill，Then 进入轻量经验索引，只读命中主题，未命中再检索，不全量预读每日记忆。
2. Given 可复用纠正、缺陷或验证遗漏，When 交付，Then 优先更新原权威入口，记录场景、原因/未知边界、可执行检查和证据；同一事件不重复计数，无新经验不新建文件。
3. Given 旧发现有新证据，When 引用，Then 已解决项退出待办，被替代结论标明关系，历史日期与验证范围保留。
4. Given 索引链接、字段或规则接线损坏，When 运行文档门禁，Then 失败并指出路径；隔离 fixture 覆盖有效和失效输入。
5. Given 当前脏工作区，When 报告验证，Then 绑定仓库/候选差异/环境/入口，区分通过、失败、跳过、未执行及交付阶段，不将结构检查冒充产品运行验收。
6. Given 普通任务或有复用价值的纠正/失败，When 事件发生或交付切片收尾，Then agent 自动沉淀，不等待用户说“整理”；有更新报告原文位置，无新增说明原因；程序检查自动触发声明不能消失或退为代码示例。
