# SP-201 整理与本地提交（2026-10-16）

## 交付内容

内置Debug UIKit悬浮入口支持直接拖选、实时准星/放大镜/轮廓、长按移位、方向罗盘、父子路径记忆。单标记带runtime/scene/window/版本/TTL身份保护，CLI经既有runtime通道读取与执行guarded tap。默认关闭，Release no-op，不新增第三方依赖。

当前交互以[space README](../README.md)和[技术设计当前契约](../../../dev/20261015-sdk-floating-picker.md)为准；初版HTML、父级/清除竖向菜单、横向工具条均仅保留历史证据。
