- **用户偏好（本产品范围）**：进一步采用任务优先的信息层级，画面、层级树和运行结果优先；保留现有深色辨识度、全部字段和交互，不通过缩小正文腾空间。
- **产品约束**：多个可分割窗格；窗格结构动作较低频，刷新、目标选择、实际状态和失败恢复必须易达。属性详情可读、草稿可复制，不执行远端写操作。
- **已验证事实**：实际仍消费 registry `@linhey/rhine-design@0.11.3`，React19/Vite7。外层窗格使用公开 Surface，内部页面使用语义 section；通过产品 headerActions 组合把标题、状态、显式刷新和公开 Menu 放同一行。移除两条只有菜单按钮的独立工具栏与重复内距，不覆盖组件私有 CSS。相同 1280px 画布和 754px 高度下，合成设备画面区域由约403px增至539px；这是本组合的测量，不代表所有页面普遍收益。
- **已验证事实**：FPS、目标关联和来源说明用公开 Popover；运行 ID/状态仅出现一次，任务、目标、暂停、unknown/partial 和失败保持常显。低频标识与证据使用 Disclosure。少量路径用公开 Stack/Inline/Disclosure 列表保留全部状态、源 ID 和命令，避免套用最小宽500px的 DataTable；不建议因此改变 DataTable 默认值。
- **已验证事实**：四场景×三主题×400/520/880×100%/200% CSS zoom 共72组长文本检查无页面横向溢出；另验三主题400px/200%下设置与来源浮层边界、帧率实际变更、详情全部属性页签、Escape焦点归还、异步复制失败和窗格菜单分割/更换/关闭。输入字段允许自身编辑滚动，必要值与错误没有删除。设备预览隐藏后释放图像，恢复可见后重新展示。
